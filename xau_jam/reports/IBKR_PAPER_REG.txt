2. ЕСЛИ В СПИСКЕ НЕТ УЗБЕКИСТАНА
════════════════════════════════════
Официально Узбекистан ЕСТЬ:
  https://www.interactivebrokers.com/en/accounts/open-account-country-list.php

В форме имя только английское: Uzbekistan. Не «Узбекистан», не O'zbekiston.
Ищи в Asia, не в Europe. В выпадашке напечатай Uzbek.

Ты попал не в ту анкету (часто US/EU — там UZ нет). Закрой вкладку и зайди так:
  1) https://www.interactivebrokers.com/en/choose-country-region.php
  2) Asia → Uzbekistan
  3) Open Account / Start Application

Не ставь Казахстан / РФ / ОАЭ / Великобританию вместо Узбекистана.
Если после этого поля Country всё равно без UZ — скинь скрин этого поля.


2b. УЗБЕКИСТАН БЫЛ, ПОТОМ ВЫЛЕЗЛА ВЕЛИКОБРИТАНИЯ
════════════════════════════════════
Так IBKR часто делает. Сначала список стран (там UZ есть), потом кидает
на английский сайт .com / .co.uk и поле Country само ставит United Kingdom.

Это витрина/сервер, не твой адрес. Жить в UK не надо.

На шаге Create Account (почта + username + пароль) поле называется
Country / Country of Legal Residence — это ГЛАВНОЕ.
Поставь снова Uzbekistan. Потом Create Account.
Гражданство (Citizenship) тоже Uzbekistan.

Можно игнорировать:
  - шапка сайта «United Kingdom»
  - адрес страницы interactivebrokers.co.uk
  - телефонный код +44, если сам не ставил

Нельзя жать Continue, пока Residence = United Kingdom.
Иначе анкета станет британской (адрес UK, налог UK) и паспорт UZ не сойдётся.

Прямая ссылка, чтобы UZ не сбрасывался:
  https://www.interactivebrokers.com/Universal/Application?country=UZ

Инкогнито. Не начинай с .co.uk.
Если поле Residence снова прыгает на UK — скрин заголовка этого поля.


3. СЕГОДНЯ — ТОЛЬКО ЗАЯВКА
════════════════════════════════════
IBKR не даёт «голый» paper без обычного счёта.
Открываем Individual. Депозит НЕ кладём.

1) Открой заявку с шага выше (сначала страна Uzbekistan), не с голого Application.
2) Тип: Individual (один человек), не IRA, не joint.
3) Логин/пароль заявки — свои. Подтверди почту.
4) Паспорт / ID, адрес, работа — как просит анкета.
5) Trading permissions: US stocks (акции США). Маржу/фьючи не набивай лишнего.
6) Если спрашивают про пополнение — банк можно указать, ДЕНЬГИ НЕ ШЛИ.
7) Отправь заявку. Жди апрув (часто часы–сутки, иногда просят ещё фото).

СТОП, если IBKR требует внести живые деньги, чтобы закончить.
Не вноси. Напиши мне. Тест без депозита.

  → Settings → Account Configuration → Paper Trading Account
  → отдельный username + пароль именно для Paper.

Вход в TWS / Client Portal: переключатель сверху LOGIN = PAPER.
Не Live. Не 7496.


5. TWS API (когда Paper уже открыт)
════════════════════════════════════
1) Поставь TWS. Войди PAPER-логином.
2) Шестерёнка → API → Settings:
   - Enable ActiveX and Socket Clients = ON
   - Socket port = 7497   (если видишь 7496 — это Live, СТОП)
   - Read-Only API можно пока оставить ON (ордера с бота ещё не шлём)
3) TWS должен оставаться залогиненным. Без него API молчит.
