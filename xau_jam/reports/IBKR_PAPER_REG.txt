2. ЕСЛИ В СПИСКЕ НЕТ УЗБЕКИСТАНА
════════════════════════════════════
Официально Узбекистан ЕСТЬ:
  https://www.interactivebrokers.com/en/accounts/open-account-country-list.php

В форме имя только английское: Uzbekistan. Не «Узбекистан», не O'zbekiston.
Ищи в Asia, не в Europe. В выпадашке напечатай Uzbek.

Ты попал не в ту анкету (часто US/EU — там UZ нет). Закрой вкладку и зайди так:
  1) https://www.interactivebrokers.com/en/choose-country-region.php
  2) Asia → Uzbekistan
  3) Open Account / Start Application

Не ставь Казахстан / РФ / ОАЭ / Великобританию вместо Узбекистана.
Если после этого поля Country всё равно без UZ — скинь скрин этого поля.


2b. УЗБЕКИСТАН БЫЛ, ПОТОМ ВЫЛЕЗЛА ВЕЛИКОБРИТАНИЯ
════════════════════════════════════
Так IBKR часто делает. Сначала список стран (там UZ есть), потом кидает
на английский сайт .com / .co.uk и поле Country само ставит United Kingdom.

Это витрина/сервер, не твой адрес. Жить в UK не надо.

На шаге Create Account (почта + username + пароль) поле называется
Country / Country of Legal Residence — это ГЛАВНОЕ.
Поставь снова Uzbekistan. Потом Create Account.
Гражданство (Citizenship) тоже Uzbekistan.

Можно игнорировать:
  - шапка сайта «United Kingdom»
  - адрес страницы interactivebrokers.co.uk
  - телефонный код +44, если сам не ставил

Нельзя жать Continue, пока Residence = United Kingdom.
Иначе анкета станет британской (адрес UK, налог UK) и паспорт UZ не сойдётся.

Прямая ссылка, чтобы UZ не сбрасывался:
  https://www.interactivebrokers.com/Universal/Application?country=UZ

Инкогнито. Не начинай с .co.uk.
Если поле Residence снова прыгает на UK — скрин заголовка этого поля.


2c. ГРАЖДАНСТВО UZ НЕТУ В СПИСКЕ
════════════════════════════════════
Сначала смотри ЗАГОЛОВОК поля. Это три разных списка.

A) Citizenship / Country of Citizenship / Гражданство
   1. Если Residence уже Uzbekistan и у тебя только паспорт UZ —
      галка «гражданство = страна проживания» / same as residence.
      Отдельно добавлять не надо.
   2. Если надо добавить: сначала галка
      «гражданство отличается от проживания», потом поле поиска.
   3. Печатай по-английски: Uzbek   (не «Узбек», не UZB).
      Ещё варианты: Uzbekistan   /   Republic of Uzbekistan
   4. Язык сайта поставь English.

B) W-8BEN / Tax treaty / «льгота по налоговому соглашению»
   Это НЕ гражданство. В этом списке UZ часто нет
   (или спрятан как USSR / Soviet Union).
   Если Uzbekistan нет — ставь
   «I do not qualify for US tax treaty benefits».
   UK / Kazakhstan / Russia сюда не ставь.

C) Issuing country паспорта (загрузка ID)
   Снова печать Uzbek по-английски.

Не выбирай чужое гражданство, чтобы проскочить.

Факт с анкеты Botir: адрес/город Ташкент и UZ живут.
Нет только выпадашки гражданства на «Подтвердите личность»
(поиск Uzbe / Узбек = «результаты не найдены», стоит Великобритания).
Это баг/дырявый список ID-шага, не отсутствие Узбекистана в IBKR.

Делать:
  1) Далее с Великобританией не жать. Чужое гражданство не ставить.
  2) В поиске гражданства набрать ровно UZB
     (ISO 3166-1 alpha-3). Не Uzbe, не UZ.
  3) Язык сайта English, если UZB пусто.
  4) Если UZB нет — эта заявка сидит на IB-UK. Адрес UZ/Tashkent
     при этом может быть. Писать в официальный Support:
     residence Uzbekistan Tashkent; citizenship has no UZB;
     move application to IB-LLC or enable UZB.
     https://www.interactivebrokers.com/en/support/customer-service.php
  5) Новую заявку только если Support скажет, что этот черновик IB-UK
     не чинится. Снова: Application?country=UZ, не .co.uk.

3. СЕГОДНЯ — ТОЛЬКО ЗАЯВКА
════════════════════════════════════
IBKR не даёт «голый» paper без обычного счёта.
Открываем Individual. Депозит НЕ кладём.

1) Открой заявку с шага выше (сначала страна Uzbekistan), не с голого Application.
2) Тип: Individual (один человек). Не IRA, не Joint, не Trust.
   Траст не нужен. Это не обход дыры гражданства UZ.
   Trust у IBKR = уже существующий юридический траст
   (договор, trustee, settlor, beneficiary). У нас его нет.
   Paper после апрува Individual дают сами. Отдельный траст
   для Paper не открывают и не требуют.
3) Логин/пароль заявки — свои. Подтверди почту.
4) Паспорт / ID, адрес, работа — как просит анкета.
5) Trading permissions: US stocks (акции США). Маржу/фьючи не набивай лишнего.
6) Если спрашивают про пополнение — банк можно указать, ДЕНЬГИ НЕ ШЛИ.
7) Отправь заявку. Жди апрув (часто часы–сутки, иногда просят ещё фото).

СТОП, если IBKR требует внести живые деньги, чтобы закончить.
Не вноси. Напиши мне. Тест без депозита.

5. TWS API (когда Paper уже открыт)
════════════════════════════════════
1) Поставь TWS. Войди PAPER-логином.
2) Шестерёнка → API → Settings:
   - Enable ActiveX and Socket Clients = ON
   - Socket port = 7497   (если видишь 7496 — это Live, СТОП)
   - Read-Only API можно пока оставить ON (ордера с бота ещё не шлём)
3) TWS должен оставаться залогиненным. Без него API молчит.


6. ЧТО ПРИСЛАТЬ МНЕ (только Paper)
════════════════════════════════════
Живой счёт (другой номер, без D) IBKR открывает сам, чтобы выдать Paper.
Его не трогаем: не логинимся, не шлём ордера, деньги не кладём.

Когда счёт Paper готов, в этот чат:
  - paper username (не live)
  - номер paper-счёта (DU… / DUR…)
  - подтверждение: логинился в TWS как Paper, порт 7497

Пароль Paper лучше вбить самому в TWS на компе. С облака до TWS
всё равно не достучаться. Если пришлёшь — только Paper, в .env,
не в git и не в TG.

НЕ присылать:
  live пароль, live username, ключи Live, порт 7496.
