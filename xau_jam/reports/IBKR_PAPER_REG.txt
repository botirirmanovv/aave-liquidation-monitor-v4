2. СЕГОДНЯ — ТОЛЬКО ЗАЯВКА
════════════════════════════════════
IBKR не даёт «голый» paper без обычного счёта.
Открываем Individual. Депозит НЕ кладём.

1) Открой заявку по первой ссылке.
2) Тип: Individual (один человек), не IRA, не joint.
3) Логин/пароль заявки — свои. Подтверди почту.
4) Паспорт / ID, адрес, работа — как просит анкета.
5) Trading permissions: US stocks (акции США). Маржу/фьючи не набивай лишнего.
6) Если спрашивают про пополнение — банк можно указать, ДЕНЬГИ НЕ ШЛИ.
7) Отправь заявку. Жди апрув (часто часы–сутки, иногда просят ещё фото).

СТОП, если IBKR требует внести живые деньги, чтобы закончить.

3. ПОСЛЕ АПРУВА — PAPER
════════════════════════════════════
Новым часто Paper дают сами (~$1 000 000 виртуальных).
Если нет:
  Client Portal → иконка человека справа вверху
  → Settings → Account Configuration → Paper Trading Account
  → отдельный username + пароль именно для Paper.

Вход в TWS / Client Portal: переключатель сверху LOGIN = PAPER.
Не Live. Не 7496.


4. TWS API (когда Paper уже открыт)
════════════════════════════════════
1) Поставь TWS. Войди PAPER-логином.
2) Шестерёнка → API → Settings:
   - Enable ActiveX and Socket Clients = ON
   - Socket port = 7497   (если видишь 7496 — это Live, СТОП)
   - Read-Only API можно пока оставить ON (ордера с бота ещё не шлём)
3) TWS должен оставаться залогиненным. Без него API молчит.
